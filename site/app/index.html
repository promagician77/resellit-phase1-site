Real extension · Chrome

Run it with the actual Chrome extension.

Same ReSellit stand-in as the demo. Here, though, Send opens a real Chrome tab: the extension’s background worker, content script and status panel do the work, and the link comes back through the same connector your ReSellit app would use.

Install in two minutes

  1. Download resellit-lister-extension.zip and unzip it.
  2. Open chrome://extensions and switch on Developer mode (top right).
  3. Click Load unpacked and choose the unzipped folder.
  4. Reload this page.

Permissions: storage, plus access to poshmark.com, localhost (your ReSellit) and *.vercel.app (this demo). No history, no tabs list, no background browsing.
